# AdvancedHeightMap
Configurable changes to the maximum amount you can change the height of terrain. Explicitly compatiable with AdvancedTerrainModifiers. 

Because the server is what actually saves the world and changes to its terrain, this mod must be installed on the server and will prevent you from connecting if you have it intsalled but it is not on the server. 
Additionally, everyone on the server must have this mod installed.

For managing configuration setting you can use an in-game configuration manager or 
change configs by editing the config file on disk as this mod has a built in file watcher.

## Features
Configure the maximum and minimum distance you can raise or lower terrain height.
